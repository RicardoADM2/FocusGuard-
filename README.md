Just a quick chrome extension that seves as a focus and productivity tool. It blocks selected websites under a previously-set countdown, also having a countdown to
access the setting page, where you add or remove sites from the block list. 

Theres really no workarounds so i think its a great tool. To set it up you just have to download the files, activate dev mode in chrome://extensions/ and click on
"Load unpacked", click the folder with all of the files and you are set.
