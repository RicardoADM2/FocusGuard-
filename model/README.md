`guard.js` is the browser inference runtime. Run `python train_guard.py` from the extension root to write the matching `meta.json`, `vocab.json`, and `weights.bin` into this folder. Do not mix generated files from different training runs.

The current weights use PERSUADE essays (The Learning Agency Lab, CC BY 4.0) and GoEmotions comments (Google Research). The raw corpora are not included. PERSUADE attribution: [The Learning Agency Lab](https://the-learning-agency.com/learning-exchange/persuade-dataset/) and [PERSUADE 2.0](https://github.com/scrosseye/persuade_corpus_2.0). GoEmotions source: [Kaggle dataset](https://www.kaggle.com/datasets/debarshichanda/goemotions) and [original paper](https://aclanthology.org/2020.acl-main.372/). Emotion labels were not used as pass/fail targets.
